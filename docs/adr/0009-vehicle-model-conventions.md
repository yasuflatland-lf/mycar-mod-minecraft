# 0009. 車のモデルの規約と、正方形の当たり判定の受け入れ

- 状態: 承認
- 日付: 2026-10-10

## 状況

車のモデルは、スクリプトで生成する仮モデルから始め、あとで Blockbench で作ったモデルに差し替えたい。差し替えのたびにスクリプトやアニメーションを直すのは避けたい。

スパイクでは、前方を +z としてモデルを作ったために、車体が前後逆に表示された。Bedrock ではエンティティの正面がモデルの -z 側になる。

Bedrock の当たり判定（`minecraft:collision_box`）は、上から見て正方形しか作れない。SUV の車体は長さ約 3.3 ブロック、幅約 2 ブロックである。

## 決定

- エンティティの正面はモデルの -z 側にする
- ボーン名を次のとおり固定する: `root`、`body`、`wheel_fl` / `wheel_fr` / `wheel_rl` / `wheel_rr`、`door_fl` / `door_fr` / `door_rl` / `door_rr`、`seat_0`〜`seat_3`
- タイヤのボーンは軸の中心に、ドアのボーンはヒンジ（前端）に pivot を置く。排気ガスの位置はロケーター `exhaust` で示す
- 当たり判定は幅 1.8・高さ 1.6 の正方形にし、車体の前後がはみ出して壁にめり込んで見えることを受け入れる
- グリルのスロットは 8 本にし、ロゴや車名は入れない。7 本スロットのグリルは Jeep の登録商標で、このリポジトリは public だからである

## 結果

- 規約を守ったモデルなら、`.geo.json` とテクスチャを差し替えるだけで使える
- 前後のめり込みを解消するには、補助のエンティティで当たり判定を足すなどの別の仕組みが必要になる。走行コアでは扱わない
